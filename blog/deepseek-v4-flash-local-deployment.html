DeepSeek V4-Flash Just Changed the Game for Local AI

Basho Parks

Updated October 28, 2026: This post describes DeepSeek V4-Flash as released in April 2026. DeepSeek shipped V4.1 Flash in September 2026, and the API name now routes to that model. The deployment method below still holds; for the current picture of what runs in a building, read Running two DGX Sparks locally.

284 Billion Parameters, 13 Billion Moving

April 24, 2026. DeepSeek drops V4-Flash, a 284-billion-parameter mixture-of-experts model under an MIT licence, and anybody running language models on hardware they own ought to pay attention. I've run it hard for a week, and it's the first model I've tested where a machine sized for one organization competes with cloud inference on production work.

The reason's memory bandwidth, the bottleneck in inference, not compute. V4-Flash is sparse: 284 billion parameters, about 13 billion firing per token, roughly 4.6 percent. A dense model like Llama 3.3 70B hauls all 70 billion across the bus on every pass; V4-Flash moves only the experts it lit up.

Memory First, Then Quantization

At FP16 the weights alone want roughly 282 gigabytes. FP8 closes the gap: about 170 gigabytes, so 192GB of VRAM holds the whole model with about 22GB left for the KV cache. That's the full FP8 model, not a squeezed INT4 build, and the quality holds for summarization, classification, extraction and code.

Thirteen billion active parameters at FP8 come to about 13GB per token; the RTX PRO 6000 Blackwell Server Edition moves 1,597 GB/s, so the roofline sits near 1,597 / 13, about 123 tokens per second. Real single-stream inference lands at 60 to 90 once you've paid for the KV cache, attention overhead and expert routing. That's bandwidth divided by active weight bytes, whatever the card.

At FP16, 384GB of VRAM covers the 282GB of weights with KV cache room. Added memory's added aggregate bandwidth, which is where sustained throughput and concurrent users come from; early testing put single-user generation at 90 to 140 tokens per second.

One Million Tokens of Context

V4-Flash carries a one-million-token context window, roughly 750,000 words, and I've watched it hold coherence across 500K. Most production work lives in the 4K to 32K range, so the full million sits largely untapped. But a tribal government loads a whole grant application, appendices attached, and checks it against program requirements with no chunking workaround.

Cloud providers cap context or charge a premium for it, because that's their meter. On your own hardware the window's a function of your VRAM and costs nothing extra per use.

Concurrency Picks the Hardware

Whether that's worth buying I can't answer from here. What decides it is your concurrency, your document lengths, how hard the serving stack has to batch simultaneous users, and which department's workflow turns out to be the real load. I don't know those until I've sat next to your people; neither do you, entirely.

The Sovereignty Argument

On hardware you own, your data doesn't leave the premises: no API call to DeepSeek's servers, no audit trail in somebody else's system. The MIT licence means you own the weights outright: modify them, redistribute them, run them fee-free, and nobody's revoking that in a terms-of-service update.

Cloud API providers have never claimed that. OpenAI, Anthropic and DeepSeek's own cloud product all reserve some right to use submitted queries for model improvement, and an opt-out doesn't change the fact that your data transited their infrastructure, which for a regulated organization is the liability. A medical practice running clinical notes through DeepSeek's cloud API is sending patient data to servers it doesn't control; locally, DeepSeek's involved in exactly zero steps.

What V4-Flash Replaces

Before April 2026 you picked between size and speed. Llama 3.3 70B is quick but caps at 128K of context and doesn't carry a 284B system's reasoning; V3 ran 671 billion parameters with 37 billion active and wanted 350GB or more of VRAM at full precision, which priced it out of most rooms. V4-Flash pairs 284B knowledge with 13B speed and ten times the context.

Summary: DeepSeek V4-Flash is an MIT-licensed 284-billion-parameter mixture-of-experts model activating about 13 billion parameters per token. At FP8 the weights land near 170GB, so 192GB of VRAM serves it, and bandwidth divided by active weight bytes gives an estimated 60 to 90 tokens per second single-stream.
