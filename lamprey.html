What you're installing

One window, any model

Lamprey puts the chat, the file tree, the terminal, a browser and git review in one window, and lets the model work across all of it. Thirty-three providers are built in. Ollama and LM Studio run with no key at all, and any OpenAI-compatible endpoint plugs in from Settings.

I built it for people who'd rather own their tools than rent them. Your conversations sit in a SQLite file on your own disk. Your API keys are encrypted through your operating system's keystore when it has one, and Lamprey won't store a key in plain text unless you tell it to. It talks to the providers and connectors you set up, and nobody else.

If you work under privilege, PHI or CUI, the controls that bound what an agent can touch don't belong in the app. They belong in the fence around it: identity, egress, metering, audit and a kill switch. That's the Security Fabric, and we put it in on-site. I wrote up the difference in LLM Harnesses, Saddles, and the Paddocks that corral them.

New in v0.34.0

It checks the edit before it lands

Small local models botch edits in boring ways. They patch a file that's changed since they last read it, miss a hunk by one indent, or delete a file and then try to edit it two steps later. Version 0.34.0 checks every change against what's on disk before it runs. It fixes the trivial misses on its own, refuses a batch of edits that contradicts itself, and keeps working a request until its goals are met or a ceiling stops it.

None of it touches the prompt. It's ordinary code sitting between the model and your files, so a small model gets the benefit for free. The idea comes from the GAVEL paper, where a deterministic world model took an 8B model from 41% to 92% task success. Lamprey's own number on a local Qwen or DeepSeek run isn't measured yet, and I won't print one until it is.

It's on by default. Settings, Advanced, World model turns it down or off.

Before you install

Check the file, then open it

Verify the download

The output has to match the SHA-256 on that file's card, character for character. On Windows, in PowerShell:

Get-FileHash .\Lamprey-x64.exe -Algorithm SHA256

On a Mac or Linux, in a terminal:

shasum -a 256 Lamprey-arm64.dmg

Windows will warn you

The Windows build isn't code-signed yet, so SmartScreen stops it with "Windows protected your PC." Once the hash matches, choose More info, then Run anyway.

So will your Mac

The Mac app is ad-hoc signed and not notarized, so Gatekeeper won't open it on the first try. Drag it into Applications, then open System Settings, Privacy & Security and choose Open Anyway. On older macOS, right-click the app and choose Open.

Linux needs one line

Mark the AppImage executable, then run it:

chmod +x Lamprey-x86_64.AppImage
