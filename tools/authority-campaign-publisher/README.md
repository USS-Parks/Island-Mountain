# Island Mountain Authority Campaign Publisher

Approval-gated NVIDIA NOOA agent for publishing the tracked Island Mountain authority campaign. Production content is never generated by a model: ordinary typed Python methods validate and execute every state transition.

Python is pinned to 3.13 because NOOA 0.0.8 is POSIX-only and does not support the repository host's default Python 3.14 runtime. Run the complete agent suite in Linux or WSL; source-only parser tests also run on Windows.

```bash
uv sync --extra dev --frozen
uv run pytest -q
uv run ruff check src tests
uv run mypy src
uv build
```

The tracked `PUBLISHING-APPROVALS.json` is a proposal until the owner runs the explicit hash-confirming approval command. No publish method accepts a proposed, stale, revoked, or blocked record.
